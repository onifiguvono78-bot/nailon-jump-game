# 仿跳一跳 · 微信小游戏

一个使用原生微信小游戏 Canvas API 实现的「跳一跳」核心玩法 Demo，零第三方依赖、无图片资源，纯代码绘制。

## 玩法

1. 小人在方块平台上待机，点击屏幕开始**蓄力**（小人会变宽变扁）；
2. 按住屏幕时间越长，松手后跳得越**远**；蓄力约 50% 时恰好落在下一块平台中心；
3. 松手后小人以弧线跳向下一块平台，**落到平台上得 1 分**；
4. 平台随机向下生成，间距与水平偏移随机，越跳越远；
5. 轻点（跳太近）或蓄满（跳过头）都会落空，掉落在平台之外判定游戏结束，显示本局分数与历史最高分，点击屏幕重新开始。

## 项目结构

```
game_jump/
├── game.json                 # 小游戏全局配置（入口、窗口、方向）
├── project.config.json       # 开发者工具项目配置
├── game.js                   # 入口：主循环 / 触摸输入 / 相机跟随 / 落地判定 / 状态机 / UI
├── js/
│   ├── config.js             # 全局参数与配色（平台尺寸、蓄力时间、跳跃距离等）
│   ├── utils.js              # 通用工具（clamp / lerp / rand / 圆角矩形绘制）
│   ├── platforms.js          # 方块平台：随机生成（向下、距离随机）、推进、裁剪、绘制
│   ├── player.js             # 小人：待机/蓄力/跳跃/坠落四态物理与绘制
│   └── score.js              # 计分与最高分持久化（wx 本地缓存）
└── README.md
```

## 代码模块说明

| 模块 | 职责 |
| --- | --- |
| `js/config.js` | 所有玩法参数集中管理（平台间距范围、蓄力上限、跳跃距离上下限、飞行弧线、配色），调难度只改这里 |
| `js/platforms.js` | `PlatformManager` 负责平台向下随机生成（`spawnNext`）、落地推进（`advance`）、视口裁剪与绘制 |
| `js/player.js` | `Player` 状态机：`IDLE → CHARGING → JUMPING → IDLE`，落空进入 `FALLING`；蓄力时长映射跳跃距离，跳跃为弧线缓动插值，坠落为重力加速 |
| `js/score.js` | `ScoreManager` 计分、`wx.setStorageSync` 持久化最高分 |
| `game.js` | 薄入口：不承载玩法逻辑，只做组装、输入与渲染调度 |

## 导入微信开发者工具

### 前置条件

- 安装最新版 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)（稳定版即可）
- 使用微信扫码登录开发者工具

### 操作步骤

1. 打开微信开发者工具，点击首页「**+**」或选择「小程序」→「**导入项目**」；
2. 项目目录选择本文件夹 `game_jump`（**不要选外层目录**，需直接选含 `game.json` 的目录）；
3. AppID 选择「**测试号**」（无需注册，直接可用；有正式 AppID 也可填入）；
4. 点击「**导入**」完成。

> 导入后项目类型会自动识别为「小游戏」（因 `game.json` 存在于项目根目录）。

### 运行与预览

- 导入完成后，开发者工具会自动编译运行，右侧模拟器即可看到游戏画面；
- 点击「预览」可用手机扫码真机体验；
- 点击「上传」可将代码包上传到微信公众平台后台，用于提审发布。

### 真机调试提示

- 本项目未申请任何接口权限，无需配置 `appid` 权限；
- 小游戏首包体积远小于 4MB 限制，无需分包。

## 自定义难度

打开 `js/config.js` 调整以下参数：

| 参数 | 含义 | 默认值 |
| --- | --- | --- |
| `PLATFORM.MIN_DIST / MAX_DIST` | 相邻平台中心距离范围 | 130 / 220 |
| `PLATFORM.MAX_DX` | 平台水平偏移上限 | 75 |
| `CHARGE.MAX_TIME` | 蓄力满时长（秒） | 1.2 |
| `CHARGE.MIN_RATIO / MAX_RATIO` | 跳跃距离 = 当前间距 × (MIN_RATIO ~ MAX_RATIO) | 0.5 / 1.5 |
| `PLATFORM.MIN_SIZE / MAX_SIZE` | 平台边长范围 | 60 / 100 |

> 跳跃距离与**当前到下一平台的距离挂钩**（而非固定值），蓄力 50% 恰好落到平台中心，轻点/蓄满都会偏离平台，节奏可掌握。

## 兼容性

- 使用原生 Canvas 2D API（`fillRect` / `arc` / `arcTo` 手绘圆角矩形，不依赖 `roundRect`），兼容旧基础库；
- 窗口信息优先使用 `wx.getWindowInfo()`，自动回退 `wx.getSystemInfoSync()`；
- 触摸事件使用 `wx.onTouchStart / onTouchEnd / onTouchCancel`，无 DOM 依赖。

## Web 版预览（无需微信开发者工具）

游戏源码同时支持在**浏览器中直接运行**，适合在没装开发者工具时快速体验玩法：

```
web/
├── index.html          # 直接双击打开（或拖进浏览器）
├── game-bundle.js      # 自动生成的单文件打包（含 wx API 浏览器适配层）
├── wx-polyfill.js      # wx.* -> 浏览器 API 适配源码
└── build-web.js        # 零依赖打包脚本
```

- **直接玩**：双击 `web/index.html` 即可在浏览器中游玩（画布固定 390×780 竖屏，桌面/手机浏览器均可，最高分存 localStorage）。输入层自动兼容**鼠标 / 触摸 / 手写笔**三种方式，且**全屏任意位置可点**（不限于画布区域）——旧内核浏览器（无 PointerEvent）自动回退到 Mouse+Touch 双通道；
- **公开分享**：已发布公网版（`web-dist/` 为发布目录），分享链接：https://9d68c3702df0498daa5772ea0f519a3a.bj8.agentos-app.net （手机/电脑浏览器直接打开即玩）；
- **平台贴图**：8 张方块贴图（`images/platforms/`）随机出现；绘制采用**完整等距立方体风格**（贴图作顶面做斜切透视，前/后/左/右四个侧面用不同深度的暗色色块形成立体厚度），消除平面感与镂空；平台仍然保持大小不一、间距不一的随机生成逻辑；贴图未加载完成前会 fallback 显示原有几何方块；
- **角色贴图**：小人已替换为 `images/character.png`（白色背景已抠除，保留完整黄色人物形象），蓄力时会压扁、跳跃时会拉伸，贴图未加载完成前会 fallback 显示几何小人；
- **去底工具**：`tools/remove_bg.py` 基于距离纯白的颜色距离 + 边缘羽化 + 底部阴影清理实现自动抠白底，原图备份为 `images/character_original.png`；
- **重新打包**：改动 `game.js` / `js/` 源码后，在项目根目录执行 `node web/build-web.js` 重新生成 bundle，并同步更新 `web-dist/` 后重新部署。

> 说明：Web 版是本地体验用，与微信小游戏共用同一套游戏源码；发布到微信仍需开发者工具或 `miniprogram-ci` 上传。

## 已知限制

- 本 Demo 聚焦核心玩法，未包含音效、连续连跳得分倍率、成就系统等增强内容；
- 跳跃方向固定朝向下一个平台（简化操作），未提供跳一跳原版的「按住旋转视角」玩法。
